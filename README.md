# 💍 Juliana Biju — Site Comercial

Projeto desenvolvido para a marca **Juliana Biju**, com foco em identidade visual,
apresentação de produtos e presença digital.

Este é um **projeto real**, criado para uma cliente, e utilizado no dia a dia
para divulgação da marca.

---

## 📌 Sobre o projeto
O site foi desenvolvido como uma landing page comercial, com catálogo de produtos
dinâmico com funções que buscam simplificar e melhorar a venda e exposição dos produtos, permitindo fácil atualização sem necessidade de backend complexo.

Principais características:
- Layout responsivo
- Catálogo dinâmico via arquivo JSON
- Estrutura simples e organizada
- Foco em clareza visual e experiência do usuário
- Envio das informações detalhadas do carrinho do cliente para a loja

---

## 🧰 Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript (Vanilla)
- JSON (catálogo de produtos)
